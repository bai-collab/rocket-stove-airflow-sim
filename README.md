# Rocket Stove Airflow Sim

國小自然／科技教育用途的火箭爐空氣流動與簡化燃燒視覺化模擬器。

## 目標

讓學生透過「設計 → 點火 → 觀察 → 修改 → 再測試」的方式，研究不同火箭爐結構如何影響：

- 自然進排氣與熱浮力
- 高溫煙氣的流動與停留
- 氧氣供應與未完全燃燒
- 二次燃燒是否形成
- 相對黑煙排出是否降低

本專案**不追求工程級 CFD 或燃燒化學精度**，定位為教學用簡化模型，不可用於推估真實燃燒效率、污染排放量或工程安全。

## Physics v2.6 重點

- 爐壁的實際開口就是進排氣通道，不需要另外放置「進氣口」或「煙囪」標記
- 二維格網求解速度、壓力、溫度與氧氣等場；畫面粒子只是 tracer
- 火源釋放簡化的 `unburnedGas`（一次燃燒後未燒完的可燃揮發氣體），氧氣不足時會增加相對黑煙 `smoke`
- 黑煙不再隨時間自動消失，只能由開放邊界流出或在二次燃燒中被消耗
- 二次燃燒只在離開一次火焰區的下游高溫區計入，並由「氧氣 + 氣流混合 + 實際停留時間」共同決定
- 稻稈殘留物拆成不可燃礦物灰、可燃未燃碳／焦渣與高速氣流帶起的飛灰；介面分開顯示生成、剩餘、沉積、燃燒與排出，避免把灰「燒掉」和「被帶出」混為一談
- 可快速載入三種「垂直升火筒、Z 型折流、雙通道預熱」爐體，比較二次燃燒、黑煙與飛灰外逸；二次燃燒不會消滅不可燃灰分
- 顯示二次燃燒強度、一次燃燒後未燃氣體（局部）、灰分與相對黑煙排出指標；未燃氣體只觀察一次火焰區外側下游，避免被整個畫布的環境空氣平均稀釋
- 三個快速爐體預設的藍色二次空氣槽會在槽口附近補入環境空氣近似，仍由高溫、氧氣、混合與停留時間決定是否發生二次燃燒
- 每個流體格都參與壓力投影；開放畫布邊界使用大氣壓基準，磚牆使用零法向流，讓壓力改變速度而不是直接搬移粒子
- 高溫煙柱的壓差會轉成同一開放連通區的等量進、出邊界通量；指標會顯示壓差、有效熱柱高度、進／出通量與壓力投影殘差
- 示蹤粒子以牆安全的速度採樣與分段碰撞移動；與畫布邊界連通的開放流體區會依「粒子缺口鬆弛 + 邊界向內通量 × 逐格目標密度」從外界補入，密閉流體區不補入
- 畫布左上角與指標面板會顯示可見／開放基準數、開放邊界補氣率、開放／密閉連通區數、開放區示蹤密度與邊界帶粒子，避免把低可見度誤判為沒有空氣
- 右側最上方優先顯示八項學生觀察指標；停滯流場、壓力／通量、粒子分布、煙囪與灰分去向等進階診斷集中在可展開的「進階診斷資訊」中

## 操作

直接開啟 `index.html` 即可使用；建議用本機靜態伺服器或 GitHub Pages。

學生建造爐體時只需要：

- 磚塊／爐壁
- 火源
- 必要時使用電風扇做對照實驗
- 橡皮擦

進排氣由爐壁留下的開口與求解出的壓力／速度場自然決定。畫布外框是大氣壓邊界與無限示蹤粒子庫；只有與外框連通的流體區可以補入，完全封閉的區域仍維持自己的粒子與氧氣條件。這個模型不是抽真空：熱柱越強，邊界進氣與排氣會一起增加，且進、出通量應接近相等。

## 建議探究

1. 完全封閉火源：觀察氧氣下降、煙累積與熄滅。
2. 建立基本煙道：觀察熱空氣上升與外界空氣由開口補入。
3. 在火焰上方增加開口：觀察是否形成較強二次燃燒並降低相對黑煙排出。
4. 開口過大或過多：觀察冷空氣是否降低高溫區溫度，使二次燃燒未必持續改善。
5. 改變 tracer 數量：確認它只改變視覺密度，不改變物理指標。
6. 長時間觀察：確認總粒子數維持開放區基準、壓力投影殘差不爆掉，且「邊界帶粒子」與「視覺重分布」和真正的物質 scalar 分開看待。

## 教育用途聲明

本模擬器只適合比較**本模型中的相對現象**。學生可以比較不同設計的氣流、二次燃燒與相對黑煙指標，但不能據此聲稱真實 PM2.5、CO、黑碳或燃燒效率改善多少百分比。
