# Physics v2.4：連續方程式與縮口加速

> 教育用近似模型，不是工程設計或安全評估工具。

## 1. 質量守恆

火箭爐內空氣受熱後密度會改變，因此採用：

```text
m_dot = rho * A * V
```

相鄰兩個截面近似滿足：

```text
rho1 * A1 * V1 ≈ rho2 * A2 * V2
```

若兩邊溫度相近、密度可近似相同，則退化為常見的連續方程式：

```text
A1 * V1 ≈ A2 * V2
```

所以，在相同流量下，截面積變小時，局部流速會提高。

## 2. 密度估算

以接近定壓的理想氣體近似：

```text
rho(T) = rho0 * T0(K) / T(K)
```

因此受熱空氣密度較低；v2.4 在估算縮口前後的質量流率時會把溫度造成的密度差納入。

## 3. 程式實作

v2.4 只在已經存在流動時套用 continuity correction；它本身不創造氣流。

驅動來源仍是：

- Boussinesq 浮力
- stack pressure
- 電風扇壓升

當流場進入一段由牆壁形成的較窄通道時：

1. 判斷目前主要流向。
2. 估算上游與目前截面的有效通道寬度。
3. 以固定 0.10 m 的第三維深度估算截面積。
4. 計算上游質量流量 proxy：

```text
m1 ≈ rho1 * A1 * V1
```

5. 估算目前截面的目標速度：

```text
V2_target = m1 / (rho2 * A2)
```

6. 只做漸進式速度修正，再交回 pressure projection。

## 4. 為什麼不代表「越窄越好」

v2.3 已加入 Darcy 型通道摩擦：

```text
Delta p_f = f * (L / Dh) * rho * V^2 / 2
```

因此：

- 適度縮口：局部速度可能增加。
- 太窄：水力直徑變小，摩擦壓損提高。
- 太長：累積摩擦壓損提高。
- 最終可能出現「局部速度高，但整體流量反而下降」。

這正是學生可以比較的設計權衡。

## 5. UI 指標

v2.4 會新增「縮口連續方程式」指標，例如：

```text
A1/A2 2.00× · v2/v1 1.65×
```

其中：

- `A1/A2`：偵測到的截面縮小比例。
- `v2/v1`：目前流場實際速度比。

實際值不一定等於面積比，因為還同時受到：

- 溫度造成的密度差
- Darcy 摩擦
- stack pressure
- 風扇壓升
- 二維格網解析度

## 6. 建議學生實驗

### 實驗 A：只改縮口

固定：

- 進氣道長度
- 火源
- 煙道高度
- 風扇設定

只改變通道截面，觀察：

- `A1/A2`
- `v2/v1`
- 平均氣流速度

### 實驗 B：縮口 vs 過窄

逐步縮小通道，觀察何時出現：

```text
局部速度增加
但整體進氣效果開始變差
```

這可用來理解「連續方程式」與「摩擦損失」不是互相矛盾，而是同時存在。
