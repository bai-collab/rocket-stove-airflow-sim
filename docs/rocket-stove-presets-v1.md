# 三種二次燃燒火箭爐構造

這三個預設是給模擬器觀察用的教學構造，不是施工圖。共同原則是：

```text
一次燃燒區 → 預熱二次空氣 → 高溫混合／停留區 → 升火筒／排煙口
```

二次燃燒主要降低黑煙與未燃氣體。稻稈灰分是不可燃固體，不能靠二次燃燒消失；構造能改善的是灰分沉積與「飛灰」外逸。模擬器中的藍色箭頭是預設的二次空氣槽，會在槽口附近補入環境空氣並施加小幅噴流，是否真的反應仍由模型條件決定。

三種預設都位於中央 Canvas 下方。空氣示蹤的畫布外框視為無限空氣庫：與外框連通的流體區依下式補入粒子，讓長時間觀察不會因粒子離開而看似抽真空：

```text
ΔN = max(0, N_open_target − N_open)
     × Δt / τ
     × (1 + min(Q_in / Q_ref, 1))
```

`N_open_target` 依開放連通區面積分配，`Q_in` 是邊界朝內的速度總量；小數量先累積，滿一顆才從外框加入。完全被磚牆包住的密閉區沒有外部來源，粒子不會被硬搬進去。右側「開放邊界補氣率」與「空氣連通區」會把這個規則顯示出來。

## A｜垂直升火筒＋雙側二次空氣槽

```text
        ↑ 排煙
     ┌──≋≋≋──┐
  ⇢  │  高溫  │  ⇠  ← 二次空氣槽
     │  升火  │
     │  🔥    │
     └──灰床──┘
        ↑ 一次空氣
```

- 受限火箱把一次空氣集中在火源下方，直立、窄的升火筒讓高溫煙氣持續上升。
- 左右開槽把新鮮空氣送入火焰上方，而不是直接吹散火源。
- 優點是路徑清楚、容易觀察；缺點是停留時間較短。

## B｜Z 型折流＋長停留混合室

```text
        ↑ 排煙
     ┌──────┐
     │  ──┐ │
     │ ┌──┘ │  ⇢ 二次空氣
     │ └──┐ │
     │ 🔥 └─┘
     └──灰床┘
```

- 交錯折流板讓煙氣左右轉向，增加混合與高溫停留時間；這一型要特別觀察灰分帳本中的排出量。
- 折流口必須保留，不可把路徑封死。
- 優點是二次燃燒較穩；缺點是折流口太窄會造成滯留與排煙不足。

## C｜雙通道預熱＋上置混合室

```text
        ↑ 排煙
     ┌─≋≋≋─┐  ← 上置混合室
  ⇢  │ ↑ ↑ │  ⇠  ← 左右預熱通道
     │ ↗🔥↖ │
     └─灰床─┘
        ↑ 一次空氣
```

- 受限中央火箱把一次空氣集中在火源下方；左右通道讓二次空氣貼著熱壁上升，先預熱再進入中央高溫區。
- 中央兩個槽口是混合點；上方空間提供停留時間。
- 優點是二次空氣較不會冷卻火焰，並可降低飛灰被高速煙流帶走；缺點是構造最複雜。

A、C 的預設火源另以較低的 `primaryAirFactor` 表示受限一次進氣，讓少量未燃氣體進入上方二次燃燒區；B 保留較開放的燃燒室，讓折流／停留效果更容易被觀察。這個參數只描述一次進氣限制，不代表真實效率百分比。

## 模擬器中的判定方式

選擇預設並點火後，觀察：

1. `二次燃燒強度` 是否上升。
2. `相對黑煙濃度` 是否下降。
3. `燃燒區相對氧氣` 是否維持在可反應範圍。
4. 灰分帳本中的 `沉積` 是否增加，而 `排出` 是否受控。

`燃燒 0.00` 是正確結果：灰分沒有被燒掉。沉積灰仍算在 `剩餘` 中；只有排出、幾何改動或按「全部清除」才會離開目前模型。
