# 火箭爐空氣流動虛擬模擬系統開發計畫

## 定位

本系統面向國小自然／科技探究活動，讓學生自行設計火箭爐結構，透過即時氣流動畫觀察點火前後的相對變化。

不追求工程級 CFD 精度，而追求：

- 即時
- 可操作
- 可比較
- 看得懂
- 能支持反覆設計與修正

## 學習循環

設計 → 點火 → 觀察 → 找問題 → 修改 → 再測試 → 比較

## 第一階段 MVP

- 放置爐壁
- 放置進氣口
- 放置火源
- 放置煙囪
- 粒子顯示空氣移動
- 簡化熱浮力
- 簡化煙囪抽氣
- 氣流順暢度
- 平均速度相對值
- 停滯比例

## 第二階段

- 儲存設計 A / B
- 雙畫面比較
- 流線顯示
- 速度熱圖
- 自動找死角與回流
- 燃料障礙物元件

## 第三階段

- 教師模式
- 參數控制
- 學生觀察紀錄
- 設計版本歷程
- 匯出實驗紀錄

## 模型限制

此模型只用於結構之間的相對比較，不可用於預測：

- 真實燃燒效率
- 實際溫度
- 黑煙排放比例
- 一氧化碳或 PM2.5
- 真實工程安全

## 核心研究問題

1. 學生能否從視覺化粒子理解空氣流動路徑？
2. 學生能否根據停滯與加速現象修改火箭爐設計？
3. 模擬是否能支持「提出設計—測試—修正」的工程探究循環？
