# 火箭爐空氣流動虛擬模擬系統開發計畫

## 定位

本系統面向國小自然／科技探究活動，讓學生自行設計火箭爐結構，透過即時氣流與簡化燃燒動畫觀察不同設計如何影響進排氣、熱流、未完全燃燒與相對黑煙。

不追求工程級 CFD 或真實排放預測，而追求：

- 即時
- 可操作
- 可比較
- 看得懂
- 能支持反覆設計與修正
- 能建立「結構 → 氣流 → 燃燒 → 黑煙」的因果理解

## 學習循環

設計 → 點火 → 觀察 → 找問題 → 修改 → 再測試 → 比較

## 目前 Physics v2.5

- 放置爐壁與火源
- 爐壁實際開口自然成為進排氣通道，不需要進氣口／煙囪標記
- 二維速度／壓力／溫度／氧氣場
- 簡化熱浮力與煙囪效應
- 狹長通道阻力與縮口連續性修正
- 未完全燃燒氣體 `unburnedGas`
- 相對黑煙 `smoke`
- 高溫 + 氧氣 + 混合形成簡化二次燃燒
- 黑煙不會隨時間自動消失
- 黑煙 scalar 背景視覺化
- 二次燃燒強度、未完全燃燒氣體、相對黑煙排出指標
- tracer 只做流場視覺化，只有真正離開畫布後才由外界邊界重新進入

- 教師模式
- 參數控制
- 學生觀察紀錄
- 設計版本歷程
- 匯出實驗紀錄
- A/B 結構與指標比較

## 模型限制

此模型只用於結構之間的相對比較，不可用於預測：

- 真實燃燒效率
- 實際溫度
- 真實黑煙排放比例
- 一氧化碳、PM2.5 或黑碳濃度
- 真實工程安全

## 核心研究問題

1. 學生能否從視覺化理解空氣如何由實際開口自然補入？
2. 學生能否理解黑煙與缺氧、溫度、混合、停留時間的關係？
3. 學生能否透過改變爐體開口與高溫區配置，形成較好的二次燃燒？
4. 學生能否根據相對黑煙指標修改火箭爐設計？
5. 模擬是否能支持「提出設計—測試—修正」的工程探究循環？
