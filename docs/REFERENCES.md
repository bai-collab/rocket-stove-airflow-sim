# References

## Windy

- Demo: https://windy.walnutlabs.in/
- Source: https://github.com/aaravriyer193/Windy
- Role in this project: reference for browser-based 2D flow visualization, user-defined obstacles, smoke/heatmap style interaction, and lightweight educational UI.

## MechSimulator Wind Tunnel

- Demo: https://mechsimulator.com/tools/wind-tunnel/
- Role in this project: reference for student-facing control design, immediate visual feedback, and converting complex fluid concepts into observable classroom interactions.

## Design decision

This project does not attempt to reproduce an engineering CFD solver. The MVP intentionally uses a simplified particle/force model so students can quickly compare structural designs.

Later versions may replace or augment the current solver with a more physically grounded 2D fluid method while preserving the same educational interface.
