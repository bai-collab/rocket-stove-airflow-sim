# Physics v2.3：進氣道阻力與電風扇

> 教育用近似模型，不是工程設計或安全評估工具。

## 1. 為什麼進氣道長度與寬度重要

火箭爐的自然抽力提供可用壓差，但空氣沿通道流動會產生摩擦與局部損失。

直通道的主要摩擦壓損可用 Darcy–Weisbach 表示：

```text
Δp_f = f (L / D_h) (ρ V² / 2)
```

因此，在其他條件相同時：

- `L` 越長 → 壓損越大。
- `D_h` 越小（通道越窄）→ 壓損越大。
- `V` 越大 → 壓損約隨速度平方增加。

矩形通道的水力直徑：

```text
D_h = 2ab / (a + b)
```

其中 `a, b` 為矩形通道兩邊尺寸。

Physics v2.3 在格網內採用 Darcy–Weisbach 的分布式形式：

```text
a_drag = - f/(2D_h) · |V| V
```

並依速度方向估計與牆面垂直的局部通道寬度。長通道因每一段都承受阻力，會累積較大的總壓損；窄通道估計出的 `D_h` 較小，因此阻力較強。

目前 `f = 0.045` 為教育視覺化用的粗糙通道係數，不代表特定磚材或真實火箭爐的量測值。

## 2. 電風扇

風扇視為額外的壓升來源 `Δp_fan`。

用壓差估算流速尺度：

```text
V ≈ C_d √(2 Δp_fan / ρ)
```

目前 UI 可調整 0–5 Pa 的有效壓升。數值經過二維格網與速度上限縮放，因此只能用來比較「無風扇／弱風扇／強風扇」的相對差異。

風扇產生的動量先加入速度場，再進入不可壓縮 pressure projection；因此風會被磚牆阻擋並沿開放通道傳遞，而不是直接推動畫面 tracer。

### 操作

1. 選「電風扇」。
2. 點畫布放置。
3. 再點同一格可依序旋轉：右 → 下 → 左 → 上。
4. 用「風扇壓升」滑桿比較不同送風強度。

## 3. 可用來做的學生實驗

### 實驗 A：進氣道長度

固定：

- 火源數量
- 煙道高度
- 進氣道寬度

只改變進氣道長度，觀察平均速度與 tracer 流向。

### 實驗 B：進氣道寬度

固定通道長度，只改變通道寬度。

### 實驗 C：自然抽力 vs 強制送風

同一爐體分別測：

- 無風扇
- 低風壓
- 高風壓

觀察風扇是否能克服長／窄通道的部分阻力。

## 4. 尚未完整處理

- 彎頭、突然縮口與擴口的局部損失係數 `K` 尚未獨立建模。
- 真實磚面粗糙度與 Reynolds number 尚未用 Colebrook 公式動態求 `f`。
- 風扇尚未使用真實 fan curve（壓力–流量曲線）。
- 二維通道的第三維深度目前假設為 0.10 m。
